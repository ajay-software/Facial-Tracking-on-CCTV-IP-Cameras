# targets/ — Drop face photos here to track people
#
# HOW TO ADD A PERSON:
# 1. Drop a clear face photo into this folder
# 2. Name it after the person:
#       John_Doe.jpg     → shows as "John Doe" in HUD
#       Jane_Smith.png   → shows as "Jane Smith"
#
# Multiple photos = better accuracy:
#       John_Doe_1.jpg, John_Doe_2.jpg ...
#
# Supported: .jpg .jpeg .png .bmp .webp
#
# Press R while HUD is running to reload new photos.
#
# NOTE: Never commit real face photos to GitHub!
